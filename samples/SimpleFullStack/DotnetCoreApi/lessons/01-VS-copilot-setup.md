# Lesson 1: Installing and Configuring GitHub Copilot

## Overview

**Goal:**  
In this lab, you will learn how to install:

- GitHub Copilot tool in Visual Studio 2022 version 17.10 or later.

**Estimated Duration:**  
10-15 minutes

**Audience:**  
 Developers, QA testers, DevOps engineers, and Technical Writers.

**Prerequisites:**

- Installed Visual Studio 2022 version 17.10 or later,
- GitHub Copilot license.

### Step 1: Install GitHub Copilot in Visual Studio 2022

First, we will install GitHub Copilot and its corresponding Visual Studio 2022 tool.

1. Open Visual Studio Installer.
2. Click on the **Modify** button for your Visual Studio 2022 installation.
3. In the **Workloads** tab, select any workload, e.g., **ASP.NET and web development**.
4. Check the box for **GitHub Copilot** from the list of **Optional components**.
5. Click the **Modify** button to install the GitHub Copilot tool.

Refer [Install and Manage GitHub Copilot in Visual Studio](https://learn.microsoft.com/en-us/visualstudio/ide/visual-studio-github-copilot-install-and-states?view=vs-2022) for more details.

---

### Step 2: Add your GitHub account to Visual Studio

1. Open Visual Studio 2022.
2. Go to **File** > **Account Settings**.
3. Click on **Add an account**.
4. Select **GitHub** and sign in with your GitHub account.
5. Authorize Visual Studio to access your GitHub account.

Refer [Add your GitHub account to Visual Studio](https://learn.microsoft.com/en-us/visualstudio/ide/work-with-github-accounts?view=vs-2022#add-a-github-account-from-the-account-settings-dialog) for more details.

You are now ready to use GitHub Copilot in Visual Studio 2022.

## Open Copilot Chat

To open the Copilot chat, click on the Copilot icon in the top right corner of the Visual Studio window and select **Open Chat Window**.  
Refer: [Visual Studio GitHub Copilot Chat Documentation](https://learn.microsoft.com/en-us/visualstudio/ide/visual-studio-github-copilot-chat?view=vs-2022)

![Image-open-gh-cp-chat](./Images/open-gh-cp-chat.png)

The GitHub Copilot chat window will open on the right side of the Visual Studio window. Its header has the following options:

1. **Chat thread dropdown:** Select a thread to view the chat history.
2. **Create new thread button:** Click to create a new chat thread.
3. **Edit thread button:** Click to open a chat in edit mode.
4. **Delete thread button:** Click to delete the current thread.
