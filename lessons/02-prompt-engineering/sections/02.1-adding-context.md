# Lesson 02.1 – Adding Context in VS Code

To maximize GitHub Copilot’s usefulness, providing relevant context is critical. The clearer the context, the more accurate and targeted Copilot’s suggestions become.

---

## How to Provide Additional Context

1. **Reference Files and Folders Explicitly**  
   Use comments to direct Copilot to specific files or folders relevant to your current task.

   **Example:**

   ```js
   // @models/user.js
   // Use the User model from the models folder to create authentication logic.
   ```

2. **Include Tools and Libraries Explicitly**  
   Mention the libraries or frameworks explicitly to ensure Copilot understands your stack.

   **Example:**

   ```js
   // Using React and Axios
   // Write a component that fetches user data from an API endpoint.
   ```

3. **Leverage Special Syntax**  
   Use `@` for file or folder references, and `#` for tags or sections.

   **Example:**

   ```js
   // @helpers/authentication.js
   #authentication
   Write a function that validates JWT tokens.
   ```

4. **Provide Comments and Inline Documentation**  
   Copilot uses comments and documentation blocks to understand your intent.

   **Example:**

   ```python
   def fetch_user_data(user_id):
       """
       Fetches user data from database by user_id.
       Returns None if user not found.
       """
       pass  # Copilot will suggest the implementation
   ```

---

## Best Practices for Maximizing Context in VS Code

- **Clearly Named Files and Folders**  
  Meaningful and descriptive names help Copilot understand context immediately.

- **Consistent Project Structure**  
  A standardized file structure (e.g., MVC, MVVM, etc.) aids Copilot in better predicting your needs.

- **Relevant Open Tabs**  
  Keep related files open simultaneously in VS Code, as Copilot can use visible files as additional context.

- **Use Workspace Settings**  
  Configure VS Code workspace settings to enhance Copilot’s understanding of project-specific conventions.

---

## Example Problem and Improved Contextual Prompt

- **Without Context:**

  > Write a function to get user information.  
  > This prompt is too broad and likely to yield generic code.

- **With Improved Context:**
  ```js
  // @models/user.js
  #database-query
  Write a JavaScript function using Sequelize ORM that retrieves a user by their ID from PostgreSQL and returns user details or an error if not found.
  ```
  This detailed prompt enables Copilot to generate highly relevant and precise code tailored to your project's specifics.
