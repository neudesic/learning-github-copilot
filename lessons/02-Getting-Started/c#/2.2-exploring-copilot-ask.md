# 🧪 Lab: Mastering GitHub Copilot Ask for Targeted Development

---

## 📝 Overview

**Goal:**  
Master GitHub Copilot Ask for targeted, contextual assistance during active development. Learn how to get precise answers about specific code sections, debug issues in real-time, and enhance your understanding of existing code without modifying it.

**Estimated Duration:** 15-20 minutes

**Audience:**  
Developers, QA testers, DevOps engineers, and Technical Writers working with Visual Studio 2022.

**Prerequisites:**
- Visual Studio 2022 (version 17.14.6 or later)
- GitHub Copilot extension enabled in Visual Studio
- Access to GitHub Copilot Chat (requires a Copilot subscription)
- Access to a .NET Core Web API sample project
- Completion of the @workspace exploration lesson (recommended)

---

## 🎯 What Makes Copilot Ask Unique?

Unlike @workspace which analyzes entire projects, **Copilot Ask** excels at:

- **Targeted Code Explanations** - Understanding specific methods, classes, or code blocks
- **Real-time Debug Assistance** - Getting help with errors and exceptions as they occur
- **Learning and Documentation** - Educational explanations without code modifications
- **Quick Context Switching** - Rapid answers while staying in your coding flow
- **Code Comprehension** - Understanding unfamiliar or complex code sections

**Key Benefits:**
- 🎯 **Focused Analysis** - Get answers about specific code without project-wide scanning
- ⚡ **Instant Responses** - Quick help without interrupting your development flow
- 📚 **Educational Value** - Learn patterns and concepts through explanations
- 🔍 **Debug Support** - Real-time assistance with errors and exceptions
- 💡 **Non-Intrusive** - Get guidance without modifying your codebase

## 🧭 Lab Steps

### 1️⃣ **Context-Aware Code Explanation**

**Select a specific method or class and ask for detailed explanations:**

1. **Open a complex method** in your editor (e.g., a service method with business logic)
2. **Select the entire method** by highlighting it
3. **Ask targeted questions:**

```text
/explain this method's logic and its role in the overall application flow
```

```text
What design patterns are being used in this selected code? Explain why they were chosen.
```

```text
Are there any potential issues or improvements in this specific implementation?
```

**Follow-up with specific concerns:**

```text
How does this method handle edge cases? What happens if null values are passed?
```

**Benefits:**
- Get detailed explanations of complex logic
- Understand design decisions and patterns
- Identify potential issues before they become bugs
- Learn from existing code implementations

---

### 2️⃣ **Real-Time Error Analysis and Debugging**

**When you encounter errors, use Ask for immediate assistance:**

**Compile-time errors:**
1. **When you see build errors**, copy the error message
2. **Ask for specific help:**

```text
I'm getting this compilation error: [paste error message]. What's causing this and how do I fix it?
```

```text
This code isn't compiling: [select problematic code]. What's wrong with this implementation?
```

**Runtime exceptions:**
1. **When debugging and hitting exceptions**, use the debugger
2. **Ask about the current state:**

```text
I'm debugging and stopped at this line [select current line]. Based on the variable values shown, what might be causing the exception?
```

```text
This exception occurred: [paste exception details]. Analyze the code context and suggest the most likely causes.
```

**Performance issues:**
```text
This method seems slow during debugging. Analyze the selected code for performance bottlenecks and suggest optimizations.
```

## 🎨 Advanced Ask Scenarios

### 🔍 **Debug Session Integration**

**During active debugging sessions:**

1. **Set breakpoints** in problematic methods
2. **When execution stops**, use Ask:

```text
Based on the current debugger state, what values should I inspect to identify the issue?
```

```text
The debugger shows these variable values [describe current state]. What's the most likely cause of the unexpected behavior?
```

### 📖 **Code Review Preparation**

**Before submitting code for review:**

```text
I'm about to submit this method [select method] for code review. What potential concerns might reviewers raise?
```

```text
Review this implementation [select code] as if you were a senior developer. What feedback would you provide?
```

**When writing tests:**

```text

```

```text

```

## 💡 Ask-Specific Best Practices

### 🎯 **Effective Ask Strategies**

**Select Before Asking:**
```text
✅ Good: [Select specific code] + "Explain this algorithm's time complexity"
❌ Vague: "How does my code work?"
```

**Be Context-Specific:**
```text
✅ Good: "This error occurs when I call SaveChanges(). What's wrong?"
❌ Generic: "Why is my code broken?"
```

**Ask Progressive Questions:**
```text
1. First: "What does this method do?"
2. Then: "How could this method be improved?"
3. Finally: "What tests should I write for this?"
```

**Use Current Context:**
```text
✅ Effective: "I'm debugging and stopped here [current line]. What should I check next?"
❌ Less useful: "How do I debug this application?"
```

### ⚡ **Rapid Development Workflow**

**Quick Understanding:**
```text
/explain [for immediate code explanations]
/doc [for documentation generation]
/tests [for test suggestions]
```

**Error Resolution:**
```text
1. Copy error message
2. Ask: "What causes this error and how do I fix it?"
3. Get solution
4. Continue coding
```

**Learning Flow:**
```text
1. Encounter unfamiliar pattern
2. Select and ask for explanation
3. Ask for best practices
4. Apply learned concepts
```

## ⚠️ **Ask vs. Workspace: When to Use Each**

### 🎯 **Use Ask When:**
- Understanding specific code sections
- Debugging active issues
- Learning from existing implementations
- Getting quick explanations during development
- Analyzing errors and exceptions
- Understanding method or class behavior

### 🌍 **Use @workspace When:**
- Analyzing entire project architecture
- Understanding project-wide patterns
- Generating documentation for the whole solution
- Planning major refactoring
- Assessing overall code quality
- Creating team coding standards
